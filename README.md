# Telegram-визитка и калькулятор грузоперевозок

## Что умеет бот
- Клиентская визитка с услугами, телефоном и Telegram.
- Кнопки: «Рассчитать стоимость», «Моя визитка и услуги», «Связаться со мной».
- Автоматический расчёт подачи машины от базовой точки до загрузки и маршрута с грузом.
- Владелец может менять визитку и тарифы; клиенты не получают доступ к настройкам.
- Характеристики по умолчанию: до 800 кг, до 5 м³, кузов 2,50 × 1,25 × 1,23 м.
- Суммы в рублях.

## Важно перед запуском
1. В `.env` укажите токен Telegram-бота и ваш личный числовой Telegram ID.
2. Не отправляйте токен другим людям и не публикуйте `.env`.
3. Если ранее вы уже публиковали токен в переписке, отзовите его через @BotFather и используйте новый.
4. Проверьте и измените базовую точку автомобиля через «Изменить визитку» → «Точка старта автомобиля». По умолчанию стоит «Москва», это лишь пример, а не точное местоположение.
5. Укажите реальные имя, телефон и Telegram username через «Изменить визитку».
6. Начальные тарифы — примерные настройки, их нужно подтвердить под свою услугу.

## Установка на Mac
```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.example .env
nano .env
python app.py
```

## Начальные тарифы
- Фиксированная часть подачи: 900 ₽
- Подача без груза: 35 ₽/км
- Маршрут с грузом: 50 ₽/км
- Минимальный заказ: 2 200 ₽

Итог = максимум из минимального заказа и суммы фиксированной части + подача без груза + путь с грузом. Время не учитывает пробки, погрузку, ожидание, платные дороги и дополнительные работы.

## Постоянная работа в облаке
Для деплоя на облачный сервер используйте переменные окружения `BOT_TOKEN`, `OWNER_TELEGRAM_ID`, а для сохранения профиля задайте `PROFILE_PATH` на постоянном диске. Не публикуйте `.env`.
